# Week 7: Hidden Markov Models

## The model

A hidden Markov model (HMM) describes a sequence of observations generated by a sequence of hidden states. At each time step t the system is in a hidden state X_t, which we cannot see, and it emits an observation E_t, which we can.

An HMM makes two assumptions. The Markov assumption says the next state depends only on the current state: P(X_t | X_0, ..., X_{t-1}) = P(X_t | X_{t-1}). The sensor assumption says each observation depends only on the current state.

An HMM is fully specified by three sets of parameters: the initial state distribution, the transition model P(X_t | X_{t-1}), and the emission (sensor) model P(E_t | X_t). With N hidden states, the transition model is an N x N matrix whose rows each sum to one.

The umbrella world is the running example. A security guard in an underground facility never sees the weather, but each morning sees whether the director carries an umbrella. The hidden state is Rain (true or false); the observation is Umbrella. The transition model says rain persists with probability 0.7, and the director carries an umbrella on 90 percent of rainy days and 20 percent of dry days.

## Inference tasks

There are four standard inference tasks on an HMM:

1. Filtering: computing the belief state P(X_t | e_1:t), the distribution over the current state given all evidence so far.
2. Prediction: computing P(X_{t+k} | e_1:t) for some k > 0.
3. Smoothing: computing P(X_k | e_1:t) for a past time k < t, using later evidence to improve the estimate.
4. Most likely explanation: finding the single most likely state sequence given the observations.

## The forward algorithm

Filtering is done recursively by the forward algorithm. The forward message f_1:t is the filtered distribution at time t. Each update has two steps: first predict by pushing the previous belief through the transition model, then update by multiplying by the probability of the new evidence and normalizing.

The forward algorithm takes time and space proportional to N^2 per step, and it does not need to store the history: each update uses only the previous message. This constant cost per step is what makes HMMs practical for online tracking.

## Smoothing with forward-backward

Smoothing combines a forward message from the start of the sequence with a backward message from the end. The backward message b_k+1:t is the probability of the future evidence given the state at time k. The forward-backward algorithm computes all smoothed estimates for a sequence of length t in O(N^2 t) time.

## The Viterbi algorithm

The most likely sequence of states is not the same as the sequence of individually most likely states. The Viterbi algorithm finds the most likely full sequence with dynamic programming.

Viterbi has the same structure as the forward algorithm, but it replaces the sum over previous states with a maximum. For every state at every time step it keeps the probability of the best path ending in that state and a back-pointer to the predecessor on that path. At the end, the algorithm follows the back-pointers from the best final state to recover the whole sequence.

Viterbi runs in O(N^2 t) time and needs O(N t) memory for the back-pointers. In practice probabilities are multiplied as sums of logarithms to avoid numerical underflow on long sequences.

## Learning with Baum-Welch

When the hidden states are never observed, the parameters are learned with the Baum-Welch algorithm, an instance of expectation-maximization (EM). The E-step runs forward-backward to compute the expected number of times each transition and emission was used. The M-step re-estimates the parameters from these expected counts.

Each iteration of Baum-Welch is guaranteed not to decrease the likelihood of the training data, but the algorithm converges only to a local maximum. Running it from several random initializations and keeping the best result is common practice.

## Applications

HMMs were the standard approach to speech recognition for decades, where hidden states are phonemes and observations are acoustic features. They are also used for part-of-speech tagging, gene finding in bioinformatics, and robot localization.
